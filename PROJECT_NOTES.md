# Заметки проекта

## Правило владельца — 4 ноября 2026

Все исправления игр, создаваемых через мастерскую, выполнять **только через задачи мастерской**. Это касается кода игры, сцены, положения объектов и стрелок, UI, ассетов и устранения z-fighting — включая небольшие и срочные исправления.

Не применять игровые исправления напрямую через Roblox Studio MCP, консоль Studio, сторонние скрипты или прямое редактирование игровых исходников. Прямой доступ к Studio допустим для чтения, диагностики и просмотра результатов; он не должен использоваться как обход очереди мастерской.

Если мастерская не справляется, исправлять её механизм и повторять игровую задачу через мастерскую. Изменения кода самой мастерской разрешены в её репозитории; работоспособность подтверждать настоящим запуском задачи мастерской. Исключения из этого правила требуют отдельного явного указания владельца.

Это правило маршрутизации работы для управляющего ассистента вне очереди. Агент действительно запущенной задачи мастерской выполняет исправления через её контролируемые инструменты с привязкой к проекту и журналом действий.
