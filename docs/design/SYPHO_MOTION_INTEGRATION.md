# Интеграция навыков Sypho для анимации, моделей и эффектов

## Решение по составу

В библиотеке остаются все девять существующих навыков, включая шесть общих навыков и три ранее подключённых пакета Sypho (карта, звуки, дополнительные проверки UI). Добавлены ещё три пакета Sypho: анимация, 3D-модели и визуальные эффекты. Всего в библиотеке двенадцать навыков; новых пакетов именно три. Предложение удалить или заменить прежние навыки отклонено: новые пакеты узкие и не перекрывают их основную работу.

[Прежний документ интеграции](SYPHO_SKILLS_INTEGRATION.md) остаётся исторической записью первого этапа. Его результаты 16/16 относятся к прежнему набору навыков. Они не считаются проверкой новых навыков движения.

## Ответственность навыков

| Навык | Отвечает за | Граница |
|---|---|---|
| `game-ui-ux` | общие решения об игровом интерфейсе и пользовательском опыте | не создаёт модели или анимации персонажей |
| `roblox-ui` | основной процесс построения Roblox UI | остаётся главным навыком для интерфейсов |
| `roblox-luau` | Luau и устройство скриптов игры | новые пакеты не заменяют общий навык программирования |
| `roblox-datastores` | сохранение и загрузку игровых данных | motion-пакеты не меняют формат данных игры |
| `create-game-assets` | визуальный стиль, бриф, 2D-ресурсы и происхождение материалов | задаёт общий художественный язык; не подменяет узкий 3D-процесс |
| `roblox-ui-styles` | утверждённые варианты стиля и их применение | UI tools проверяют интерфейс, но не меняют тему автоматически |
| `sypho-roblox-map` | планирование карты, геометрия и проходимость | карта — композиция пространства; пакет 3D-моделей отвечает за отдельную модель |
| `sypho-roblox-sfx` | поиск и проверка звуков, сборка звукового банка | не отвечает за визуальные эффекты |
| `sypho-roblox-ui-tools` | дополнительные статические проверки и превью UI | не заменяет основной дизайн и сборку интерфейса |
| `sypho-roblox-animation` | позы и подготовка ключевых кадров для Roblox-рига | не задаёт игровую механику; не должен заменять или перезаписывать существующие анимации |
| `sypho-roblox-3d-model` | локальный Blender-процесс создания/обработки геометрии, UV/текстурной раскраски, проверок, рендера и экспорта в Roblox-форматы | по умолчанию использует контролируемый генератор мастерской или предоставленную геометрию; сложный производственный меш требует отдельной художественной проверки |
| `sypho-roblox-vfx` | рецепт, проверка и Luau для внешнего вида эффекта | не задаёт урон или попадания; не меняет камеру и UI без прямой необходимости задачи |

Общий стиль, бриф, 2D-ресурсы и происхождение материалов остаются за `create-game-assets`. Новые 3D-инструменты используют локальный Blender, установленный пользователем: проверен Blender 5.2.3 LTS (`e13b728c6880`), Python 3.13.13 и встроенный NumPy 2.3.4. Доступны создание/обработка геометрии, проверки, UV/текстурная раскраска и выпечка, рендер-превью и экспорт. Это локальный путь для предоставленных или контролируемо созданных моделей, а не обещание автоматически производственного сложного ассета. Установка Blender агентом не выполнялась.

Анимационные конвертеры могут удалить целевую папку или заменить одноимённые дочерние анимации в Luau, который они выдают. Поэтому целевой путь должен быть уникальной пустой папкой, принадлежащей текущей задаче; перед применением требуется просмотреть выданный Luau. VFX-пакет управляет только видом эффекта. Наличие рецепта или встроенной текстуры Roblox не означает право на распространение стороннего набора ассетов. Публикация игры автоматически не выполняется.

`RESOURCE_MAP.json` фиксирует преобразование исходных путей. Luau-файлы хранятся с суффиксом `.txt` по правилам загрузчика мастерской. `docs/skill-imports/sypho-motion-sources.json` содержит список файлов, исключения, исходный commit, лицензию и хеш каждого включённого файла. Неизменённый upstream `SKILL.md` хранится рядом с адаптированной инструкцией в каждом пакете.

В экспорт анимации не включён `upload_animation.py`; в 3D-пакет не входят пакетный генератор и `upload_asset.py`. Из VFX workflow исключены сетевой поиск/загрузка текстур, сервер рецептов, сборщик и харвестер Studio. Не перенесены upstream-оркестраторы, локальные настройки, внешние сервисы и ключи. Зависимости не устанавливаются автоматически. Офлайн-скрипты выполняются только в папке активной задачи с отключённой сетью; игровые изменения проводятся исключительно контролируемыми инструментами этой задачи. Анимационный пакет отвечает за позы и временную структуру кадров, но не определяет игровую механику. VFX-пакет задаёт вид эмиттера/эффекта, но не урон и попадание; камера и UI меняются только если этого требует задача. Частицы и процедурные заглушки сами по себе не подтверждают права на сторонние наборы материалов и не заменяют сложную production-модель.

У адаптации сохранён точный `LICENSE.txt` upstream. Лицензия разрешает использование навыков и созданных с их помощью результатов в собственных проектах, включая коммерческие игры, и изменение навыков для собственного использования. Она запрещает продажу навыков и изменённых копий, а также включение их в платный набор. При бесплатном распространении лицензия просит указать канал SyphoDev. В README upstream нет конкретной ссылки, поэтому ссылка не выдумана. У любых сторонних инструментов и материалов остаются собственные условия; этот импорт не подтверждает права на сторонние asset packs.
