# Навыки для разработки и оформления игр Roblox

Исходное исследование: 1 ноября 2026 года. Выполнены поиск через Skills CLI, просмотр исходных репозиториев и содержимого выбранных навыков. На момент исходного исследования внешние навыки не были установлены.

Дополнение 2 ноября: создан собственный шестой пакет [roblox-ui-styles](../../.agents/skills/roblox-ui-styles/SKILL.md), версия 1.0.0. Он автоматически закрепляется в новых и существующих проектах и передаётся art/ui/assets/qa вместе с выбранными токенами, иконками и исходным визуальным референсом. Три заготовки сравниваются без генерации игры и Studio; основной инженерный UI-навык сохраняется. Переносимый архив находится в `outputs/roblox-ui-styles.zip`.

Обновление 2 ноября 2026 года: в проект включены полные проверенные пакеты game-ui-ux, roblox-luau, roblox-datastores, roblox-ui и create-game-assets из commit `19d93f97c9c1ea0f8b306e77aa81e0d3e352d3e9` (Apache-2.0). Источники, лицензии и контрольные суммы находятся в `docs/skill-imports/installed.json`. Они автоматически загружаются в реестр при старте сервиса и закрепляются за новым проектом; существующий проект получает недостающие пакеты перед следующей задачей. Агент получает полные инструкции и ссылки своего назначения по роли. Основной UI пакет — roblox-ui; альтернативный roblox-gui можно закрепить явно. Пакеты не подменяют друг друга одновременно.

Автоподключение проверено на новом проекте через работающий API, журнал SQLite и дашборд без вызовов ручного импорта/закрепления: `docs/verification/automatic-skills.json`. Проверка назначения инструкций по ролям, необходимых возможностей Studio и сохранения закреплённых версий находится в `tests/default-skills.test.ts`. Исходные Python файлы сохранены для полноты пакета; импорт их не запускает. Это проверка подключения и передачи инструкций. Профильные проверки сохранений, UI и ресурсов в Roblox отмечаются отдельно и не считаются пройденными по факту импорта.

### Источники и проверка

[awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) — сторонняя библиотека с лицензией Apache 2.0. На момент проверки API GitHub показывал 6 353 звезды; последнее изменение 28 октября 2026. Прочитан [roblox-ui](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/other-engines/roblox-ui/SKILL.md) и просмотрен [create-game-assets](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/create-game-assets/SKILL.md).

[roblox-brain](https://github.com/TabooHarmony/roblox-brain) — сторонняя библиотека с лицензией MIT, около 150 звёзд GitHub; последнее изменение 15 октября 2026. Прочитаны [roblox-gui](https://github.com/TabooHarmony/roblox-brain/blob/main/skills/gameplay/roblox-gui/SKILL.md) и [roblox-lighting](https://github.com/TabooHarmony/roblox-brain/blob/main/skills/gameplay/roblox-lighting/SKILL.md). Содержимое выбранных UI навыков ориентировано на реализацию и проверку интерфейса. Оно не заменяет исследование текущего оформления популярных игр.

### Команды для установки выбранных кандидатов

Команды приведены для последующего решения об установке. В ходе исследования они не выполнялись.

```powershell
npx skills add gamedev-skills/awesome-gamedev-agent-skills@roblox-ui
npx skills add TabooHarmony/roblox-brain --skill roblox-gui
npx skills add TabooHarmony/roblox-brain --skill roblox-lighting
```

Для первого технического прототипа стоит выбрать один основной UI навык, использовать доступные проверки Studio и подключать остальные навыки по роли и задаче.

## Вывод для каталога стилей

В просмотренных материалах не найден готовый проверенный каталог актуальных визуальных стилей Roblox вместе со всеми игровыми экранами. Для этой функции нужны датированные референсы, собственные правила пакетов стиля и регулярное исследование реальных игр. Найденные навыки помогают реализовать и проверить выбранное оформление.
