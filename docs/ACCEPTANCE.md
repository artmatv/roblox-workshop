# Матрица требований версии 1.4

Статус описывает проверенное состояние реализации, а не обещание результата. Полная приёмка включает подключённые аккаунты, Studio и контрольные игры; часть сценариев нельзя подтвердить тестом локальной бизнес-логики.

Уточнение пользователя от 2 ноября: продолжать разработку плагина и дашборда, не заниматься оформлением самих игр. Контрольные проекты приостановлены, прежние материалы сохранены. Их полная игровая приёмка остаётся отдельной проверкой системы; выбор стиля сейчас не запрашивается.

Дополнение пользователя от 2 ноября: вместо сборки игровых прототипов для выбора оформления использовать заготовки стилей, упаковать их в `roblox-ui-styles` и автоматически применять в проекте. Этот выбор подтверждает визуальное направление; работа готового игрового интерфейса проверяется позднее в Studio.

## Что нужно для полной приёмки

Когда будет возобновлена игровая приёмка: выбрать оформление трёх утверждённых концепций; согласовать окончательные спецификации и бюджеты; выполнить производство и проверку игрового UI в Studio, по три доработки и расширение через дашборд; проверить собственный облачный test experience, сохранения, покупки и аналитику; получить пользовательские результаты реального телефона. Только после этого все соответствующие строки могут получить статус «проверено».
