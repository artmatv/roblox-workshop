# Восстановление и обновление

Данные находятся в `data`. Не удаляйте SQLite, tasks, projects, skills или captures при обновлении приложения.

## Резервная копия

В разделе «Сборка и проверки» нажмите «Резервная копия». Сервис использует online SQLite backup и копирует файлы проектов, задач и ресурсов в `data/backups/<id>`. Копия содержит `backup.json` только после завершения. Привязанные DPAPI секреты можно расшифровать только тем же Windows аккаунтом; резервная копия не является переносимым экспортом ключей.

Перед восстановлением остановите сервис. Проверка копии:

```powershell
node --import tsx scripts/restore-backup.ts <id>
```

Применение после проверки:

```powershell
node --import tsx scripts/restore-backup.ts <id> --apply
```

Текущая база сохраняется рядом с пометкой before-restore. После запуска незавершённые агентные задачи восстанавливаются с сохранённой сессией, отправленные команды Studio ожидают сверки. Не повторяйте неизвестную внешнюю загрузку или публикацию без проверки Creator Hub/источника.

## Откат игры

Откат в дашборде создаёт новую ревизию на основе выбранного manifest, спецификации, стиля и набора навыков. Результаты проверок и телефон сбрасываются. Повторная публикация требует нового подтверждения. Неожиданные изменения Studio сначала сохраняются snapshot; их можно принять отдельной версией.

## Обновление приложения и Codex

1. Создайте резервную копию и остановите сервис.
2. Сохраните `package-lock.json` и используйте `npm ci`.
3. Запустите `npm run verify`, пересоберите плагин, выполните отдельную проверку App Server и Studio.
4. Только после проверки новой версии протокола изменяйте PINNED_CODEX. Смена версии без проверки блокируется.

Смена аккаунта останавливает новые задачи, очищает квоту и не продолжает сессии прежнего аккаунта. Приложение не меняет настройки сна, автопополнения баланса или автозапуска Windows.

## Что делать при остановке

| Причина | Действие |
| --- | --- |
| Ожидает Studio | Подключите выбранную Studio и возобновите плагин |
| Ожидает квоты | Проверьте данные источника; включите разрешённое автоматическое возобновление либо продолжите после обновления |
| Ожидает бюджета | Просмотрите оценку, расход и резерв, измените лимит своим решением |
| Неопределённая команда | Переподключите плагин для повторной отправки результата; при отсутствии результата осмотрите сцену до ручной сверки |
| Несовместимый навык | Прочитайте пакет, проверьте доступность инструментов, закрепите проверенную версию |
| Автоматический баланс недоступен | Используйте вручную подтверждённый баланс с датой; Costs API остаётся отдельным источником расходов |
